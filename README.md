# Data Analytics Portfolio 📊

Welcome to my data analytics and predictive modelling showcase repository. This repository contains end-to-end data science projects focused on supply chain optimization and urban transportation analysis.

---

## 🚀 Featured Projects

### 1. DataCo Supply Chain Analytics & Predictive Modelling
*   **Core Objective:** Cleaned and integrated an e-commerce supply chain dataset of 180,000+ orders to identify key drivers behind late deliveries, order cancellations, and payment risks.
*   **Tech Stack:** Python, Pandas, Scikit-Learn (Random Forest Classification).
*   **Key Deliverable:** [View Jupyter Notebook](./Final_DataCo_project.ipynb) | [Download Executive PPTX](./Fok%20Koe%20Kian%20Freddy_DataCo.pptx)
*   **Summary:** Built a Random Forest model trained on ~32,800 orders to translate predictive metrics into actionable, high-risk operational mitigation strategies.

### 2. New York Yellow Taxi Performance Analysis
*   **Core Objective:** Investigated urban transit efficiency, trip durations, and pricing behaviors using historical NYC yellow cab trip data.
*   **Tech Stack:** Python, Pandas, Matplotlib, Seaborn.
*   **Key Deliverable:** [View Jupyter Notebook](./Yellow%20Taxi.ipynb)
